# Japan Trip 2026

Интерактивный путеводитель по Японии на 9–18 ноября 2026 года.

Сайт статический: для локального просмотра достаточно открыть `index.html` в браузере.

Публикация настроена через GitHub Pages и GitHub Actions. После загрузки репозитория в GitHub откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
